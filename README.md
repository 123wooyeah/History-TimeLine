# 历史人物&事件时间轴

> History Timeline — 直观对比不同历史人物与事件所处的时代

一个基于 Web 的交互式历史人物&事件时间轴工具。输入历史人名或事件，自动检索生卒年/发生时间并在横向时间轴上显示其生命区间与事件节点，多个人物在 Y 轴方向累加排列，方便直观对比他们所处时代的重合与差异。支持本地人物库 + Wikipedia + Wikidata 在线检索，可分享链接、导出图片。

| 本地事件库 | 56 个重大历史事件 |
| 更新日期 | 2026-09-11 |

## 核心功能

- 📅 **横向时间轴** — ECharts 自定义渲染，人物生命区间以彩色横条展示，支持滚轮缩放、拖拽平移
- 🏛️ **朝代标尺** — 时间轴顶部叠加 23 个中国朝代色带，悬停显示朝代名称与起止年份
- ⚡ **历史事件标记** — 垂直虚线 + 菱形图标标记历史事件，持续事件显示横向范围带，一目了然
- 🔍 **智能搜索** — 人物/事件双模式切换，本地库 + Wikidata 在线混合搜索，自动补全
- 🌐 **Wikidata 在线检索** — JSONP 方式调用 Wikidata API，自动过滤结果，支持 7 天本地缓存
- 🔗 **分享链接** — 一键复制当前人物+事件组合的分享链接，打开即可加载相同配置
- 📷 **导出图片** — 将当前时间轴导出为 2 倍分辨率 PNG 图片，方便保存和分享
- ↕️ **多种排序** — 支持按默认顺序、生年、卒年、朝代、领域 5 种方式排序
- ✨ **推荐组合** — 内置多组预设组合：唐代诗人、三国人物、千古帝王、重大事件等
- 🌙 **深色主题** — 深褐色暗色调 + 金色文字点缀，护眼且富有历史感

## 技术架构

### 技术栈

`TypeScript` `ECharts 5` `Vite 5` `CSS3` `HTML5` `Wikidata API` `JSONP` `localStorage`

### 架构特点

纯前端 SPA 架构，无需后端服务，部署成本极低。数据层采用「本地优先 + 在线补充」的双层策略：本地预置 105 位高频历史人物保证秒级响应，Wikidata 在线检索覆盖长尾需求。在线结果自动缓存到 localStorage，减少 API 调用次数。

> 💡 **为什么用 JSONP 而不是 fetch？**
>
> Wikidata 官方 API 不支持 CORS 跨域，浏览器端直接 fetch 会被拦截。使用 JSONP（callback 参数）可以绕过 CORS 限制，是纯前端方案的最佳选择。

## 使用说明

### 开发模式

```bash
cd history-timeline
npm install
npm run dev      # 启动开发服务器 http://localhost:5173
npm run build    # 构建生产版本到 dist/
```

### 搜索技巧

- 切换「人物」或「事件」标签搜索不同类型的数据
- 输入关键词后自动搜索，**本地结果优先显示**，在线结果稍后出现在下方
- 人物搜索支持按姓名、字号、朝代、领域多维度模糊匹配
- 事件搜索支持按事件名称、类别、地点、描述多维度模糊匹配
- 点击「在线」标签的结果会从 Wikidata 加载详细信息，首次加载约 1–3 秒
- 已加载过的在线人物/事件会缓存到本地，下次秒开

### 分享与导出

- 点击「🔗 分享」按钮自动复制当前人物组合的链接
- 点击「📷 导出」按钮将时间轴保存为 PNG 图片
